# StatLab Multi-Sport Analytics

StatLab is a multi-sport analytics project that uses PostgreSQL and Power BI to analyze synthetic MLB and NBA player performance data.

## Dashboard Pages

- MLB Overview
- MLB Player Comparison
- NBA Overview
- NBA Player Comparison

## Tools Used

- PostgreSQL
- SQL
- Power BI
- DAX

## Features

- Interactive player and team filters
- Player comparison tables
- Batting average and home-run analysis
- Points, rebounds, and assists analysis
- Performance trends over time
- KPI cards and conditional formatting

## Data Disclaimer

This project currently uses synthetic 2025 demonstration data. The statistics do not represent real professional athletes.

## Project Structure

- `dashboard/` — Power BI report
- `sql/` — database creation, sample data, and SQL views
- `screenshots/` — dashboard previews
- `data/` — source datasets, when applicable
